STUBBY — LOGO ASSETS
====================

Mark: a brand-orange app tile holding a monospace [ • ] — brackets around a
stubbed value. Brand orange is #F97316; the glyph is pure white #FFFFFF.

FILES
-----
stubby-mark.svg            Primary mark, vector (scales to any size).
stubby-favicon.svg         Same mark, optimized for the browser tab / favicon.
stubby-lockup-light.svg    Mark + "stubby" wordmark — for LIGHT backgrounds.
stubby-lockup-dark.svg     Mark + "stubby" wordmark — for DARK backgrounds.
stubby-mark-1024.png       Raster mark, 1024px (app icon / store listing).
stubby-mark-512.png        Raster mark, 512px.
stubby-mark-256.png        Raster mark, 256px.
stubby-mark-128.png        Raster mark, 128px.
stubby-mark-64.png         Raster mark, 64px.
stubby-mark-32.png         Raster mark, 32px (favicon raster fallback).
stubby-mark-16.png         Raster mark, 16px (favicon raster fallback).

USAGE NOTES
-----------
• Prefer the SVGs anywhere they're supported — they stay crisp at every size.
• PNGs have transparent corners (the tile's rounded square), so they sit
  cleanly on any background.
• The wordmark in the lockup SVGs uses IBM Plex Mono, with SF Mono / system
  monospace as fallback. Install IBM Plex Mono for an exact match.
• Clear space: keep at least one bracket-width of padding around the mark.
• Don't recolor the tile or stretch the mark; for monochrome contexts, fill
  the whole mark in a single ink color.
